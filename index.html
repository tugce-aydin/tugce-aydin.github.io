Featured Project · C++ Process Model

BOF Dynamic Process Model

A simplified physics-based dynamic simulation of the Basic Oxygen Furnace steelmaking process developed in C++.

The model tracks carbon, silicon and manganese oxidation, oxygen consumption, scrap melting, reaction products, mass balance and a simplified energy balance throughout the oxygen blow.

A dataset generated by the C++ simulator is used to train machine-learning surrogate models for endpoint time and endpoint temperature prediction. A PySide6 desktop application connects the physics model and ML layer in a single engineering interface.

996 s Baseline endpoint time
1635.6 °C Estimated endpoint temperature
0.0599 wt.% Final carbon
1,000 ML simulation cases
